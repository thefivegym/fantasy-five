Once per season, before your first lineup. A lineup from a GitHub login with no sign-up is not accepted. Your GitHub login is your player name.

Email and reminders

GitHub issues are public, so your email never goes into one in plain text. This page encrypts it in your browser (RSA-OAEP, SHA-256) with the organizer's public key before the issue opens. The issue, the repo and the site only ever hold the scrambled version. Only the organizer's private key, which is not on GitHub, can read it.

Then press Create on GitHub. A bot saves your sign-up, comments, and closes the issue within a minute or two. Signing up again replaces your email and reminder setting.

Reminders arrive as a GitHub mention. Check your GitHub email notifications are on (GitHub → Settings → Notifications → Email for participating and @mentions).
